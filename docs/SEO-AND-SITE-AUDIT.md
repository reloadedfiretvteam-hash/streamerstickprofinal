## 2. Website Build Audit

### 2.1 Build Pipeline (`script/build.ts`)

1. Cleans and creates `dist`.
2. Vite build with `vite.config.cloudflare.ts`; `outDir` overridden to `dist`.
3. Esbuild for `worker/index.ts` → `dist/_worker.js`.
4. Writes `dist/_routes.json` (include `/*`; exclude assets, robots, verification files).
5. Runs `scripts/prerender-blog.ts` (blog HTML + sitemap + robots in dist).
6. Runs `scripts/seo-audit.ts`.

- Prerender receives SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_KEY from env when available.

---

### 2.2 Routes (`client/src/App.tsx`)

- **CanonicalTag** rendered once; all routes get correct canonical and hreflang.
- **Routes:** `/` (MainStore), `/shop`, `/blog`, `/blog/:slug`, `/tutorials`, pillar pages, `/l/:country/:pageType/:slug`, auth, policy, checkout, success, admin, etc.
- **Shadow domain:** When host is secure host, only `/`, `/checkout`, `/success` and not-found are exposed.
- **Lazy loading:** Blog, Tutorials, pillar, Location, etc. lazy-loaded; MainStore, Shop, Checkout critical.

---

### 2.3 Worker (`worker/index.ts`)

- **CORS:** streamstickpro.com, www, secure.
- **API routes:** /api/auth, products, checkout, orders, admin, webhook, track, track-visit, customer, free-trial, blog, seo-ads, ai-assistant, email-campaigns; /api/health, /api/debug, /api/catalog-summary, /api/seo-page/...
- **Redirects:** Applied before catch-all; DB then static.
- **Crawler /l/*:** Served before redirect handler.
- **Sitemaps:** /sitemap-index.xml, /sitemap-pages.xml, /sitemap-posts.xml, /sitemap.xml (dynamic; fallback to static file on error).
- **Catch-all:** ASSETS.fetch; on failure, index.html for SPA.

- **Storage:** `getStorage(c.env)` uses VITE_SUPABASE_URL and SUPABASE_SERVICE_KEY (or ROLE/ROLL or anon).

---

### 2.4 Storage & Supabase (`worker/storage.ts`, `worker/helpers.ts`)

- **helpers:** `getStorageConfig` from Env; `getStorage` returns `createStorage(config)`.
- **Blog:** `getBlogPosts()` filters `is_published === true`, orders by `published_at`; `mapBlogPostFromDb` maps to camelCase (including `publishedAt`). Admin and API expect `is_published`, `published_at`, `category`, `keywords`, `meta_description` (migration `20260213000000_blog_posts_worker_columns.sql` adds if missing).
- **SEO pages:** `getSeoPageByPath`, `getSeoPagesForSitemap` for location/topic pages.
- **Redirect map:** `getRedirectMap()` for 301s.

## 4. Recommendations (Optional)

1. **Tutorials page:** Add a small FAQ or HowTo schema for “Adding IPTV Media Players” if you want richer SERP.
2. **prerender-blog:** Prefer env (e.g. VITE_SUPABASE_URL, SUPABASE_ANON_KEY) over hardcoded Supabase URL/key for consistency.
3. **robots.txt:** Consider referencing `sitemap-index.xml` in addition to `sitemap.xml` so engines can use the index when you scale.
4. **Crawl-delay:** Optional to remove for Googlebot (it’s ignored); keep for Bing/Yandex if you want to throttle.
