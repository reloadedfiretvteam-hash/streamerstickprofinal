# Deliverable 20: AEO & Zero-Click Optimization Checklist

Answer Engine Optimization (AEO) targets featured snippets, AI overviews, and voice so content gets cited without a click.

## Content

- [ ] **Answer-first:** First 40–60 words are a direct, concise answer to the query (P1 snippet).
- [ ] **Conversational language:** Natural sentences; question-style headings (Who, What, Where, When, Why, How).
- [ ] **Question-based targets:** Cover "People Also Ask" and voice queries from voice-query-map.
- [ ] **Passage-ready:** One clear paragraph per question (80–90 words) for position #0.

## Schema & structure

- [ ] **FAQPage** on every location and pillar page (faq_json / SEOSchema).
- [ ] **BreadcrumbList** on every page.
- [ ] **HowTo** for setup guides; **Product** / **Service** where relevant.
- [ ] **Organization** and **WebSite** sitewide.

## E-E-A-T & citation

- [ ] Author/source clarity (seo_experts, byline where applicable).
- [ ] No fake stats; use [CHANNEL_COUNT], [IPTV_PRICE] placeholders where needed.
- [ ] Trust signals: uptime, users served, privacy (see trust-signals doc).

## Voice & zero-click

- [ ] Target 10K voice queries (voice-query-map); map to target pages.
- [ ] "Hey Google / Alexa" style phrasing in meta and P1.
- [ ] Submit to IndexNow on publish/update so Bing/Yandex see changes fast.

## PAA (People Also Ask)

- [ ] Identify PAA questions for each cluster (e.g. "Is IPTV legal?", "What is a jailbroken Fire Stick?").
- [ ] One FAQ entry per PAA with a direct 2–3 sentence answer.
