# AEO Practices Library – 1000s of Answer Engine Optimization Tactics

Use this library to optimize for **featured snippets**, **People Also Ask**, **voice search**, **AI overviews**, and **zero-click** visibility. Total practices across all files: **2,000+**.

## Quick reference (research-backed)

- **P1 / paragraph snippet:** 40–60 words (≈300 characters max for featured snippet).
- **FAQ answers:** 40–60 words; conversational; one clear idea per answer.
- **Lists (featured):** 3–6 items for PAA; "How" questions win lists ~47%.
- **Voice:** Natural language; question-style headings; Speakable schema (US, English).
- **Schema:** FAQPage, HowTo, BreadcrumbList, Organization, WebSite, Speakable (JSON-LD).
