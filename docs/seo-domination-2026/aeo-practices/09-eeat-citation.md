# AEO: E-E-A-T and Citation (100+)

## Experience

1. Use “we’ve tested” or “we use” when you have hands-on experience.
2. Use “in our testing” before stating a result (speed, quality).
3. Use “we stream” or “we run” when describing your own use.
4. Use “our team uses” when it’s team experience.
5. Use “based on our setup” when giving device/app recommendations.
6. Use “we recommend” with a short reason from experience.
7. Use “we’ve seen” when describing common issues or outcomes.
8. Use “in practice” when contrasting with theory.
9. Use “real-world” when describing tests or usage.
10. Use “hands-on” when you’ve used the product/service.
11. Use “we’ve tried” when comparing options.
12. Use “our experience shows” when stating a conclusion.
13. Use “we’ve found” when sharing a finding.
14. Use “we’ve used [X] for [time]” when you have longevity.
15. Use “we run [X] on” when describing your stack.

## Expertise

16. Use “expert” only when you can back it (role, credentials).
17. Use “specialist” for a focused area (e.g. streaming, IPTV).
18. Use “years in [field]” when true.
19. Use “certified” only when you have a real certification.
20. Use “trained” when you have formal training.
21. Use “our experts” when you have named or identifiable experts.
22. Use “author” or “written by” with a byline when possible.
23. Use “reviewed by” when content is reviewed by a qualified person.
24. Use “[Name], [Title]” in bylines or author boxes.
25. Use “credentials” or “background” in author bio.
26. Use “industry experience” when you have it.
27. Use “technical background” when relevant.
28. Use “streaming specialist” or “IPTV specialist” when accurate.
29. Use “support team” when citing internal support experience.
30. Use “engineers” or “technical team” when they contributed.
31. Use “editorial team” when you have an editorial process.
32. Use “fact-checked” when you have a fact-check step.
33. Use “updated [date]” to show freshness.
34. Use “last reviewed” when you have a review cycle.
35. Use “accuracy” or “we verify” when you have a process.

## Authoritativeness

36. Use “trusted” only when you have a basis (reviews, tenure).
37. Use “recognized” only when you can cite recognition.
38. Use “cited by” when others link or reference you.
39. Use “featured in” when you’ve been featured (and it’s true).
40. Use “partnership” when you have formal partners.
41. Use “awards” only when you have real awards.
42. Use “industry standard” only when defensible.
43. Use “leading” only when you have evidence.
44. Use “established [year]” when true.
45. Use “serving [X] customers” when you have a real number.
46. Use “used by” when you have B2B or known users.
47. Use “recommended by” when you have a real recommendation.
48. Use “approved” or “certified” only when you have documentation.
49. Use “compliance” when you follow regulations (e.g. GDPR).
50. Use “transparent” when you state policies (refund, privacy).
51. Use “terms of service” and “privacy policy” in footer.
52. Use “contact” and “about” for accountability.
53. Use “company” or “brand” when establishing entity.
54. Use “physical address” or “registered” when you have one.
55. Use “business registration” when relevant and true.

## Trustworthiness

56. Use “we don’t” when stating what you don’t do (e.g. sell data).
57. Use “secure” only when you have security measures.
58. Use “encrypted” when you use encryption (checkout, data).
59. Use “payment processor” when you name a known processor.
60. Use “we never store” when you don’t store sensitive data.
61. Use “refund policy” with a clear, honest description.
62. Use “no hidden fees” only when true.
63. Use “clear pricing” when you show prices upfront.
64. Use “honest” or “transparent” when you back it with facts.
65. Use “we disclose” when you disclose affiliations or limitations.
66. Use “affiliate” or “partner” when you have affiliate links.
67. Use “sponsored” when content is sponsored.
68. Use “opinion” when stating subjective views.
69. Use “your experience may vary” when outcomes differ.
70. Use “check with your [provider/law]” when jurisdiction matters.
71. Use “we recommend verifying” when users should double-check.
72. Use “source” or “according to” when citing external facts.
73. Use “as of [date]” when info can go stale.
74. Use “subject to change” when policies or offers change.
75. Use “contact us to confirm” when details need confirmation.
76. Use “see terms” when you refer to legal docs.
77. Use “see privacy policy” when you refer to data use.
78. Use “opt out” when you offer opt-out options.
79. Use “unsubscribe” when you offer email unsubscribe.
80. Use “data we collect” when you list what you collect.

## Citation and sources

81. Use “according to [source]” when citing.
82. Use “[Source] states” or “[Source] reports” for attribution.
83. Use “research shows” only when you can link or name the research.
84. Use “study” or “survey” with a date and source when possible.
85. Use “official” only when linking to an official source.
86. Use “documentation” when citing vendor or platform docs.
87. Use “support article” when citing help docs.
88. Use “as per” for formal attribution.
89. Use “cited in” when you reference another article.
90. Use “see” or “read more” with a link for further reading.
91. Use “source: [URL]” or “via [name]” in lists or tables.
92. Use “last updated” or “accessed [date]” for time-sensitive sources.
93. Use “primary source” when you link to the original.
94. Use “secondary source” when you cite a summary or article.
95. Use “expert quote” when you have a real quote and permission.
96. Use “interview” when you conducted one.
97. Use “press release” when you cite one (with date).
98. Use “statistics” with a source and date.
99. Use “data from” when you use a dataset or report.
100. Use “internal data” when you use your own (and it’s accurate).
101. Use “user feedback” when you have real feedback (and permission).
102. Use “reviews” when you cite real reviews (with attribution).
103. Use “case study” when you have a real case (with permission).
104. Use “test results” when you have real tests (describe method briefly).
105. Use “benchmark” when you have comparable, documented tests.
106. Use “comparison” when you state how you compared (criteria, date).
107. Use “disclaimer” when you need to limit scope (e.g. legal, region).
108. Use “not legal advice” when you’re not a lawyer.
109. Use “not financial advice” when you’re not a licensed advisor.
110. Use “consult a [professional]” when they should get expert advice.
